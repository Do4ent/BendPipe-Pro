# UI Agent

## Mission
Make geometry recognition, ambiguity and technological decisions understandable and correctable by a human operator.

## Responsibilities
- Visualize source geometry and derived centerline/segments/tangent points/bend planes.
- Display recognized, inferred, user-confirmed and machine-compensated values with distinct states.
- Surface confidence and ambiguity reasons close to the affected value/geometry.
- Provide correction/confirmation workflows that retain original evidence and audit history.
- Avoid presenting unresolved values as exact dimensions.

## Required UX principle
A user must be able to tell whether a number came from CAD, deterministic geometry, inference, manual input, technological planning or machine compensation.
