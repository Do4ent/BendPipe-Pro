## Non-negotiable domain rules

1. Recognized/design geometry is independent of machine, tooling and material compensation.
2. CLR is the centerline radius unless an explicitly named alternative radius is used.
3. Every bend owns its nominal geometric CLR/radius; tooling validates compatibility and must not silently redefine the part.
4. Unknown or ambiguous imported dimensions remain explicit unknown/inferred values with confidence and reason.
5. Imported geometry and manually constructed geometry go through the same validation engine.
6. A calculation failure is never reported as a successful check.
7. Production export requires a release gate; draft export must be clearly identified as non-production.
8. Project-level validation includes hidden/inactive tubes.
9. Migrations may not invent geometry silently.

## Recovery milestone

Milestone M1 is **Trusted Geometry Core**.

M1 is complete only when the same project produces the same centerline, CLR, bend angles and total centerline length in geometry, validation, reports, simulation inputs and export; changing tooling cannot mutate canonical part geometry; and required validation failures block production release.

## Known VC207R7 audit blockers

### P0
- A01: arc length uses an inconsistent radius and overstates centerline length.
- A02: failed checks can appear as OK.
- A03: tooling references are array-index based and can change meaning after sort/delete.
- A04: fallback manufacturing defaults inject Steel/Generic CNC values inconsistent with the agreed copper/manual-or-non-CNC domain.
- A05: manufacturing export has no mandatory release gate.

### P1
- A06: editing angle can be reverted by stale `angleFormula`.
- A07: newer editor paths bypass part of validation.
- A08: readonly protection does not cover all newer commands.
- A09: project conflicts among inactive tubes can be hidden from the status panel.
- A10: import normalization can synthesize geometry such as LINE(100).
- A11: open-preview bounds checks differ from working validation.
- A12: DXF export replaces bends with chords.
- A13: Undo/Redo is not implemented.
- A14: simulation does not yet model separate manual and non-CNC machine workflows.

### P2 / architecture debt
- A15: bend geometry is not independently persisted from tooling.
- A16: composite offsets are flattened in the newer tree.
- A17: localization conflicts with late UI mutations.
- A18: offline packaging/versioning is inconsistent.
- A19: universal STEP/DWG/DWFx import is not yet implemented.
