# BendPipe-Pro 0.1.0-rc.6

Right-click the ribbon or header toolbar and choose **Компактный вид без подписей**. This fourth display mode uses compact icon buttons while hiding captions. Tooltips and accessible command names remain available. Ribbon and header preferences are saved separately, restored after reload, and retained when switching between Classic and CAD Workspace. Existing compact mode with captions remains available.

The layer commands and project model from rc.5 are unchanged. This release changes toolbar presentation only; source evidence, canonical geometry, confidence and machine compensation are unaffected. Browser checks cover reduced ribbon height and increased viewport space, hidden captions, visible icons, accessible names/tooltips, real command execution, keyboard menu navigation, stage changes, reload and independent mode switching.

Download the ZIP, extract it and open **BendPipe_Pro_CAD_Workspace.html** in Chromium. This remains an evaluation release candidate. Recognition and manufacturing limitations from rc.4 still apply: 80005311 and 80005313 retain blocked whole-project imports, and unresolved geometry, material, tooling and machine settings retain manufacturing blockers. Export project JSON before changing browser origins or HTML files.
