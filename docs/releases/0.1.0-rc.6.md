# BendPipe-Pro 0.1.0-rc.6

Right-click the ribbon or header toolbar and choose **Компактный вид без подписей**. This fourth display mode uses compact icon buttons while hiding captions. Tooltips and accessible command names remain available. Ribbon and header preferences are saved separately and restored after reload. Existing compact mode with captions remains available.

CAD Workspace is now the only supported interface and the only HTML in the package. Classic switching, restoration code and CSS are removed, along with the obsolete right-column Checks/Technology cards, their rendering code and the old Layers button that opened Overview. The shared project editors, viewer, native tools, actual production checks and layer commands remain. The standalone builder directly embeds CAD Workspace; the separate prototype builder and duplicated CI round trip are removed. Historical release notes remain unchanged.

The project model from rc.5 is unchanged: source evidence, canonical geometry, confidence and machine compensation are unaffected. Browser checks cover reduced ribbon height and increased viewport space, hidden captions, visible icons, accessible names/tooltips, real command execution, keyboard menu navigation, stage changes, reload and independent mode switching. Existing import, editing, persistence, WebGL restart and export scenarios now all run on the same public HTML.

Download the ZIP, extract it and open **BendPipe_Pro_CAD_Workspace.html** in Chromium. This remains an evaluation release candidate. Recognition and manufacturing limitations from rc.4 still apply: 80005311 and 80005313 retain blocked whole-project imports, and unresolved geometry, material, tooling and machine settings retain manufacturing blockers. Export project JSON before changing browser origins or HTML files.
