# BendPipe-Pro 0.1.0-rc.3 — CAD reference interface

This prerelease applies the user-approved dark-blue TubeBender CAD interface to the real project application, not to a generated image.

## User-visible changes
- Larger, responsive application header with existing native project and tube controls.
- Reworked five-stage ribbon and command appearance with labelled CAD actions.
- Rebalanced project tree / real WebGL viewport / real properties inspector.
- Geometry quick actions for radius, dimensions and saved views, routed to native runtime APIs.
- New live viewport status displaying active tube, computed centerline length, bend count, and material (unknown values are not fabricated).
- Project inspector header reflecting real selected tube and project state.
- Technology navigation shortcut; existing Source, Geometry, Technology, Machine and Release workspaces preserved.
- Original DWFx import, editable tube geometry, actual production gate, project serialization and classic layout remain in place.

## Scope and restrictions
This is a functional UI update, not a guarantee that every icon in the illustrative design corresponds to a new independent CAD algorithm. Existing native panels own geometry editing and measurements. Screenshot dimensions or sample tube parameters are *not* inserted into projects. User project data is not migrated or replaced.

## Installation
Download the ZIP or the CAD Workspace HTML, extract if needed, and open BendPipe_Pro_CAD_Workspace.html with Chromium. The classic standalone HTML is also included. Export project JSON before switching browser origins.

## Verification
Publish only after Node tests, both HTML syntax checks, Playwright CAD checks, SHA-256 verification and release archive packaging complete successfully.
