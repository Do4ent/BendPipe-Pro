# BendPipe-Pro 0.1.0-rc.2

This release candidate includes the accepted CAD Workspace interface from PR #38.

## Download and start

Download the ZIP, extract it, and open **BendPipe_Pro_CAD_Workspace.html** in Chromium. The package also includes a separate classic HTML, a short instruction file and SHA-256 checksums. Both HTML builds report releaseVersion 0.1.0-rc.2; the CAD/project schema version remains unchanged.

## Changes

- Five task workspaces: Source, Geometry, Technology, Machine and Release.
- A unified Properties / Source / Checks inspector using the original selection editor, provenance evidence and real production gate.
- Right-click ribbon/header display options: icons with captions or icons only, persisted separately for each panel with tooltips and accessible names.
- Menu keyboard isolation prevents Enter/Space from repeating a CAD operation while selecting display settings.
- Mobile inspector sizing leaves bottom navigation reachable.
- Classic view restores original controls without copying project data.
- Duplicate Save and All Panels ribbon entries removed; Evidence opens the Source tab.

## Verification

Publication is gated by Node regression, both HTML syntax checks, full Chromium acceptance, checksums and the complete real-source import → recognition → edit → save/reload → project JSON export/reopen scenario on the actual release HTML.

Canonical geometry, provenance and import production blockers must survive the round trip. Unverified manufacturing export must remain blocked.

## Limitations

This is an evaluation release candidate. Source fixtures are not certified production parts. The full browser round trip covers 80004806; archived 80005311/80005313 currently have integrity/container coverage only.

The reported identity 10102473 conflicts with source labels naming 10104935; metadata/geometry dimension conflicts remain. Production requires human confirmation of unresolved evidence, tooling, material and machine settings.

Workspace captions initially use Russian, while native panels retain their existing language settings. Optional OCR may require external resources. Browser storage depends on origin/file handling; export project JSON before switching files or browser origins. No measured editing-speed improvement is claimed.
