# BendPipe-Pro 0.1.0-rc.9

Remove the retired Classic interface from the source and release. The old title bar, hidden workbench host, duplicate construction tree and project controls, unused editing dashboard, mockup theme/layout observer and decorative window/navigation/snap controls are deleted. The shared editor and runtime now live under `src/application`, with editor controls and current shell styles in `src/ui`.

The real unfold drawing has an explicit bottom tab. Task stages and ribbon commands return to the 3D view. Native Measurements and Editing launchers are retained in All Panels without adding duplicate header controls. The header Settings action opens the existing settings dialog directly and preserves read-only protection.

Geometry, source evidence, confidence, project schema and machine compensation are preserved. Regression coverage includes load/reload without retired DOM, view tools, unfold/3D transitions, live dimension editing and reopening, plus the complete DWFx import → recognition → edit → save/reopen → export scenario.

Download the ZIP, extract it and open **BendPipe_Pro_CAD_Workspace.html** in Chromium. This remains an evaluation release candidate. Unresolved geometry and missing material/tooling/machine settings retain manufacturing blockers. Save project JSON before moving between browser origins or HTML files.
