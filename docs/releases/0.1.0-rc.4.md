# BendPipe-Pro 0.1.0-rc.4

This release candidate stabilizes the accepted CAD reference workspace.

- Missing, blank, boolean, invalid and incomplete segment dimensions remain unknown in the live length summary. The summary identifies editable rows as its source and retains a reason and confidence for unresolved length.
- Canonical geometry builders, local-frame derivation and legacy row conversion reject missing, boolean, string and sparse numeric inputs instead of silently substituting coordinates or dimensions. Six obsolete source-text assertions now check actual rejection behavior.
- Unavailable native commands and delegated command failures report failure. Reference viewport controls disappear in classic mode.
- Integration CI builds the primary release HTML before running tests that open it, eliminating the missing-artifact HTTP 503 failure.
- Live WebGL2 rendering and native browser storage after a full Chromium restart are included in the normal acceptance suite.
- Both integration and tag release CI verify the complete DWFx import, recognition, edit, save/reopen and project JSON export/reopen scenario on the primary CAD Workspace HTML, with separate evidence files.
- Tag-based release CI is the single publisher. The obsolete branch-specific rc.3 publisher has been removed.
- DWFx rendering mask `0x1` is decoded according to the source toolkit without consuming extra bytes or altering geometry. Real-source regressions now cover 80005311 and 80005313, preserving explicit recognition blockers.

Download the ZIP, extract it and open **BendPipe_Pro_CAD_Workspace.html** in Chromium. A classic standalone HTML, instructions and SHA-256 checksums are included.
