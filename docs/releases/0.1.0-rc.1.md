# BendPipe-Pro 0.1.0-rc.1

First release candidate of the standalone browser CAD editor, built from the integration branch `develop`.

## Verified scope

- Authoritative DWFx sources 80004806, 80005311 and 80005313 are archived unchanged with SHA-256 integrity tests.
- The full Chromium scenario for 80004806 covers import, recognition of nine editable candidates, UI editing, local workspace save/reload, project JSON export and reopening.
- Canonical geometry and source provenance survive editing and persistence. Machine compensation remains downstream.
- Unverified imported candidates retain their production blockers; manufacturing export produces no file while release requirements are unresolved.
- Node regression, standalone build, inline JavaScript syntax, Chromium startup, rendering and persistence are enforced in CI.

## Limitations

This is a release candidate for evaluation. The source fixtures are not certified production parts. For 80004806, the reported identity 10102473 conflicts with source labels naming 10104935; metadata/geometry dimension conflicts also remain. Manufacturing requires human confirmation of unresolved evidence, tooling, material and machine settings.

The full browser scenario currently covers 80004806. The other two DWFx sources have integrity/container tests, but have not passed this same complete recognition/edit/export scenario.

The release distributes a standalone HTML and a SHA-256 checksum. Optional OCR functionality may require external resources. Keep the source DWFx and exported project JSON as separate artifacts.
