# BendPipe-Pro 0.1.0-rc.5

Right-click the ribbon or header toolbar and select **Компактный вид**. Compact buttons retain icons and captions in one row; a compact ribbon gives more height to the real CAD viewport. Display preferences are saved separately for the ribbon and header. The existing caption and icons-only modes remain available, including keyboard menu navigation and classic layout restoration.

Use the **Слои** button in Geometry or enter **LAYER**, **LA** or **СЛОИ** in the command palette to open the existing native layer manager. Create layers, select the current layer, assign selected objects, change visibility, freeze/lock state, color, line type and display lineweight. These presentation and editing-permission properties are serialized with the project; they do not change nominal tube dimensions or machine compensation. The manager follows the familiar [AutoCAD layer-properties workflow](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-LT/files/GUID-B297EBD9-D68C-47E1-87CE-1B3798496599.htm).

Existing custom command aliases have priority over new defaults. For example, if LA was already assigned to Move, it stays assigned to Move; LAYER and the palette's Layers entry remain available. Command history and recent commands are preserved. Unavailable layer APIs report a visible failure.

Browser regressions verify compact layout height, separate preference persistence, mobile navigation, classic restoration, real typed layer commands, assignment, color, visibility, lock/freeze behavior and project reload without changing geometry or source evidence. Release publication also requires the existing Node, full Chromium and real DWFx round-trip gates.

Download the ZIP, extract it and open **BendPipe_Pro_CAD_Workspace.html** in Chromium. This is an evaluation release candidate. The recognition and manufacturing limits documented in rc.4 still apply: 80005311 and 80005313 retain blocked whole-project imports; unresolved source geometry, material, tooling and machine settings cannot be released as manufacturing programs. Export project JSON before switching browser origins or HTML files.
